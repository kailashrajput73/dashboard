
# PART 1: WEB ADMIN PANEL

Centralized web system for administrators and store managers to run products, inventory, referral partners, quotations, dispatch, warehouse, users, and reports. Supports bulk Excel operations, QR/Barcode integration, role-based access, and real-time dashboards.

Phase-1

## 1. Master Management

### 1.1 Category Management
**Functional Requirements:**
- Create new product categories (name + required info)
- Edit existing categories
- Disable (not delete) inactive categories to preserve history
- Search/filter categories by parameters
- Display total product count per category

**Features:**
- Create categories
- Update categories
- Activate/deactivate categories
- Search & filter
- Category-wise product count display
- Duplicate name prevention

phase-2

### 1.2 Sub Category Management
**Functional Requirements:**
- Create multiple subcategories under a selected parent category
- Each subcategory linked to its parent category
- Excel template provided for bulk upload
- Uploaded data validated before saving (no duplicates/incorrect entries)
- Export all subcategory data to Excel

**Features:**
- Create, edit, delete subcategories
- Map subcategories to categories
- Bulk upload via Excel
- Export subcategory list
- Search & filter
- Duplicate validation

phase-3 

### 1.3 Brand Management
**Functional Requirements:**
- Create, update, manage multiple brands
- Every product must be linked to a brand
- Activate/deactivate brands without affecting historical transactions
- Prevent duplicate brand names

**Features:**
- Create/update/manage brands
- Activate/deactivate brands
- Associate brands with products
- Search & filter
- Duplicate validation

phase-4

### 1.4 Product Management
**Functional Requirements:**
- Auto-generate unique product code for every new product
- Define product name, display sequence, reorder level (ROL), regular discount
- Assign product to category, subcategory, brand
- Support multiple aliases per product
- Support multi-language product names (so partners can search by local names)
- Auto-generate QR code for every product
- Bulk import/export via Excel

**Features:**
- Auto-generated product code
- Product name
- Product sequence
- Reorder Level (ROL)
- Multiple alias names
- Multi-language product names
- Regular discount field
- Brand mapping
- Category & subcategory mapping
- Product group assignment
- QR code generation
- Bulk Excel import
- Bulk Excel export
- Search by code, name, alias, brand

phase-5

### 1.5 Product Group Management
**Functional Requirements:**
- Create multiple product groups
- Assign 2+ products to each group
- A product may belong to multiple groups
- Partners can filter by group in the mobile app

**Features:**
- Create product groups
- Assign multiple products
- Edit groups

- Search product groups
- Group-wise product filtering

phase-10

## 5. RFQ (Request for Quotation) Management
**Functional Requirements:**
- Partners create RFQs from the mobile app by selecting products
- Each RFQ routed to admin/authorized store manager for review
- Admin/manager applies customer-specific special discounts
- Admin/manager allocates reward points on approval
- System auto-notifies partner via app on approval, showing approved price + reward points
- Admin/manager specifies **Store Pickup** or **Home Delivery** + schedules date/time — visible to partner
- When partner arrives in-store, approved RFQ remains **editable until final dispatch**:
  - Add new products
  - Modify quantities
  - Remove products
  - Add products via product search OR barcode/QR scan
- System maintains full RFQ change history (who changed what, when) for audit

**Features:**
- Create RFQ via mobile app
- View/manage all RFQs in Admin Panel
- Filter RFQs by partner, category, product, date, status, manager
- Export RFQ reports to Excel
- Approve with special discounts
- Allocate reward points at approval
- Record approving admin/manager
- Send approval notifications to app
- Display approved special pricing in app
- Select store pickup or home delivery
- Schedule pickup/delivery date & time
- Update approved RFQs before dispatch
- Add/remove products before final billing
- Modify quantities before dispatch
- Add products via barcode/QR scan
- Full RFQ update history & audit log
