## How to test

From the repository root in PowerShell:

```powershell
backend\.venv\Scripts\python.exe backend\scripts\test_pg_connection.py
```

Or from `backend/`:

```powershell
.\.venv\Scripts\python.exe scripts\test_pg_connection.py
```

The actual connection URL is already configured in the local, ignored `backend/.env`. Do not commit it or share its password. Confirm no application tables exist with:

```powershell
& "$env:ProgramFiles\PostgreSQL\17\bin\psql.exe" -U quotation_app -h 127.0.0.1 -p 5432 -d quotation_db_pg -c "SELECT count(*) AS application_tables FROM pg_catalog.pg_tables WHERE schemaname NOT IN ('pg_catalog', 'information_schema');"
```

The count should be `0`. The connection script itself uses only `SELECT version()` and `SELECT 1`.

To check the Mongo API remains independently available, start it from a separate PowerShell window at the repository root using its existing dependencies and MongoDB setup:

```powershell
uvicorn backend_refactor.server:app --host 127.0.0.1 --port 8000
```

Then check its existing root route with `Invoke-RestMethod http://127.0.0.1:8000/api/`. No route or Mongo connection code was changed in this row.

## Linux equivalent

On Debian/Ubuntu, install PostgreSQL and Python venv support, start the `postgresql` service, create the same role/database, and set `DATABASE_URL` in `backend/.env`:

```bash
sudo apt update
sudo apt install postgresql postgresql-client python3-venv
sudo systemctl enable --now postgresql
sudo -u postgres psql
```

In `psql`, run `CREATE ROLE quotation_app WITH LOGIN;`, then `\password quotation_app`, then `CREATE DATABASE quotation_db_pg OWNER quotation_app;`. Copy `backend/.env.example` to `backend/.env` and set its URL. Create a venv and run the test:

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
backend/.venv/bin/python backend/scripts/test_pg_connection.py
```

Fedora/RHEL use their `dnf` PostgreSQL server/client packages and distribution-specific cluster initialization; the service is `postgresql`.
