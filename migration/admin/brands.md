# Brands

Use **Brands** in the Catalog section to maintain product brands and their logos.

- Select **Add brand**, enter a brand name, and choose **Upload photo** to select a logo file or paste a picture URL. Select **Create brand** to save it. New brands are active by default.
- Search by brand name. Use **All**, **Active**, or **Inactive** to filter the list.
- Select **Photo** or the logo to edit the brand name or logo. Select **Save changes** when finished. Renaming a brand updates the brand name on products linked to it.
- Select the product count to see linked products. Products match by brand ID or by a case-insensitive brand-name match.
- Select the pause icon to make a brand inactive. Use **Inactive** to find it later; select the play icon to activate it again.
- To delete, select the trash icon and confirm with the admin contact number and passcode. Deleting a brand also permanently deletes all products linked by brand ID or matching brand name. Check the confirmation message for the number of products removed.
