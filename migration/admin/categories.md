# Categories

Use **Categories** in the Catalog section to organize products.

- Search by typing part of a category name. Use **All**, **Active**, or **Inactive** to filter the list.
- Select **Add category**, enter a category name, and optionally upload a home photo or paste a picture URL. Select **Create category** to save.
- Select the category's photo thumbnail or its **Photo** / **Add photo** action to edit the name or photo, then choose **Save changes**.
- Use the play/pause icon to activate or deactivate a category.
- Select the product count to expand the products currently linked to that category.
- The delete action removes the category, its subcategories, and every product in that category. Confirm with the admin contact number and passcode only if you intend to remove them; this is a cascade delete.
