# Dashboard

The Dashboard is a live operations snapshot, not a monthly or quarterly report pack.

Metric cards show SKU count, stock units, low-stock count, RFQ counts by pending/approved/dispatched status, partners with approved KYC versus total partners, and dispatch sales value for the recent seven-day window. Select a metric to open its related module. Dispatch value includes the bill count; when there are no dispatches, the value is shown as a dash.

Needs review lists pending RFQs and opens RFQ Management. Moving fast lists products with recent dispatch movement; In stock, not moving lists products without movement in the displayed sales window. Module shortcuts open catalog, taxonomy, warehouse, sales, imports, team, and settings pages. Product type and Product class shortcuts follow their visibility settings.

If the snapshot cannot load, check the displayed API error and configured API URL. HTTPS pages cannot load a plain HTTP API in the browser.
