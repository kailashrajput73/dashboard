# Signing in

On the Admin dashboard sign-in page, enter your contact number and passcode, then select **Sign In**. Both fields are required. If either is blank, the page identifies the missing field. If sign-in fails, read the message in the error dialog and dismiss it before trying again.

After a successful sign-in, the dashboard opens. The **Create an admin account** link opens a placeholder until the Register page is migrated.

Do not share your passcode. Sign out when finished, especially on a shared computer.
