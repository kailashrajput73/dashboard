# Dashboard menu

The sidebar is grouped into Overview, Catalog, Warehouse, Sales, and Admin. Sales contains RFQs, Partners, Service requests, and Dispatch, in that order. Money config is not in the web menu.

Select Service requests to search and update plumber/electrician requests. Other menu items open their corresponding dashboard screens; screens still being migrated may show a placeholder.

Product type and Product class appear according to the saved catalog taxonomy settings. Sign out clears the saved admin session and opens the `/login` placeholder; the login flow is added separately.

The sidebar stays at the left of the viewport while page content scrolls in its own pane. If the menu exceeds the available window height, scroll inside the sidebar menu.
