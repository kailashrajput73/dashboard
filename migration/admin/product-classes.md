# Product class

Use **Product class** to view and manage the classes assigned to catalog products.

- Search by class name. The list groups class values without regard to letter case and sorts them by name. If a product has no saved class, the dashboard may infer one from its product name, such as SDR11 or Sch 40.
- Select the product count to see products in that class.
- To remove products in a class, select its trash icon and confirm with the admin contact number and passcode. This permanently deletes matching products; it does not delete a separate class record. The message reports how many products were removed.
- Class values come from catalog data; this page has no create or edit form.
