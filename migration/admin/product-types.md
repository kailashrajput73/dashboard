# Product type

Use **Product type** to view product types from the catalog, add or remove a type photo, and manage products of that type.

- Search by type name. Use **All**, **Active**, or **Inactive** to filter the list.
- Select **Add photo** or the photo to upload an image, paste a picture URL, or remove the current photo. Select **Save photo** to save it. This changes the photo only, not the type name.
- Select the product count to see products assigned to the type.
- Select the pause icon to make the type inactive; select the play icon to activate it again.
- To remove products of a type, select its trash icon and confirm with the admin passcode. This permanently removes every product with that type; it does not remove the type entry. The message reports how many products were removed.
