# Racks

Use Racks to assign catalog products to warehouse locations.

- Select the add icon, enter a rack name, and set the number of rows and columns. New racks start at 3 rows by 5 columns. Rows must be 1-26 and columns 1-100; locations are generated from row letters and column numbers (for example, `A1` and `B2`).
- Select any location to choose a catalog product and assign it to that slot. Occupied locations can also be selected for reassignment. **Assign product** opens the first empty location, or the first location if all are occupied.
- The rack view shows its name, dimensions, and each location's occupied state.
- Select the delete icon to attempt to delete a rack. There is no confirmation dialog. A rack with assigned products cannot be deleted; clear its assignments first.
