# Create Admin Account

Register only when setting up a new admin account. Enter a company name, GSTIN, contact number with at least six characters, and a passcode of at least four characters. GSTIN is converted to uppercase as entered.

Select Create Account to register. The app then signs in with the same contact and passcode, saves the session, and opens Dashboard. Existing admins can use the Sign in link instead.

Registration creates a persistent admin account. Keep the passcode available for future sign-ins and do not use this flow for disposable test data on production.
