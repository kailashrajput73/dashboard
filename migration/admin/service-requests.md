# Service requests

Use this screen to review plumbing and electrician requests and update their lifecycle.

Filter by status or service type. Search customer name, phone, service type, description, city, or area. Select a request in the list to see its address, description, and history.

In Lifecycle, choose Pending, In progress, Completed, or Cancelled. Enter the recommended person's name and phone when applicable, and add an admin note. Select Save update to persist the fields. The history records the lifecycle status, actor, time, note, and any recommended person recorded by the API.

Updates are persisted immediately and appear in request history. The Service requests sidebar item is added in the requested menu-fix row.
