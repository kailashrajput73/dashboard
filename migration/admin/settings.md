# Settings

## Catalog tabs

Product type and Product class switches control whether those catalog tabs appear in the sidebar. The spreadsheet columns remain Type and Class when a tab is hidden. Changes are saved in this browser and reflected in the menu when navigating to another page.

## Wipe entire catalog

The temporary **Delete all catalog data** action deletes all products, categories, subcategories, product types, brands, product groups, and pricing history. The server requires the admin login contact and passcode.

This operation cannot be undone and is intended only before a clean master import. Do not use it on production or real catalog data.
