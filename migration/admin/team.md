# Team Management

Use this screen to manage admin, store manager, and staff accounts.

Search by name or contact number. Use the role filters to narrow the list. Summary counts show active accounts and totals for each role. Each user displays their current role, active status, and permission labels.

The team list is fetched without using the browser cache so a visit or refresh shows current user data.

Select the switch to activate or deactivate an account. Select Edit to change the name, contact number, role, or status. Select the plus icon to create a user; name, contact, and a passcode of at least four characters are required. The role determines the default permissions shown and sent when saving.

The current API does not support changing an existing user's passcode. Role permission labels are stored/displayed, but this screen does not enforce route access by role.
