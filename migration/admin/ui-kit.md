# Shared interface parts

The shared web interface parts are the building blocks used by later dashboard screens:

- Buttons provide primary, secondary, ghost, and danger actions, with size, loading, disabled, and optional icon states.
- Inputs provide labels, placeholders, optional validation text, secure entry, keyboard hints, and multiline entry.
- Cards group related content; chips represent selectable filters.
- Headers show a title, optional subtitle, back callback, and optional action area.
- Empty states explain when a list has no content and can offer a call to action.
- Dialogs display focused content; error dialogs display a message and a Dismiss action.

These parts do not represent a standalone dashboard task screen. The current preview is for development and will be removed when the login entry is built.
