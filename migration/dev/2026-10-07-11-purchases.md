# Row 11: Purchases

**Status:** Built; manual checks are waiting in `migration/PENDING.md`.

## Built

Migrated the current Expo Purchases screen to React web at `web/src/pages/PurchasesPage.tsx` and connected `/purchases` in `web/src/App.tsx`.

The page loads products, racks, and purchase history; supports single purchase entry, bulk CSV upload, searchable product selection, optional rack/slot assignment, From/To date filtering, report totals, purchase template download, and filtered purchase-line CSV export. It uses existing `GET /catalog`, `GET /racks`, `GET /purchases`, and `POST /purchases` API helpers. No backend or Expo files were changed.

Bulk CSV parsing, header normalization, column aliases, validation conditions/messages, and request payload match the current Expo implementation. The export header is the existing template header: `productCode,quantity,listPrice,purchaseDiscount,rackId,rackSlot`.

## Expo differences and reasons

- Expo uses React Native `SafeAreaView`, `FlatList`, `TouchableOpacity`, `AppModal`, `DocumentPicker`, and Expo Router. Web uses semantic DOM layout, browser file input, HTML select controls, the shared web modal/button components, and React Router. These are platform substitutions; user-facing task flow and messages are retained.
- Expo uses custom rack and slot option lists; web uses native browser `<select>` controls populated with the same rack/slot data. The empty-rack-slot message is unchanged.
- The web purchase picker reads the same `lastPurchasePrice` value as Expo through a local optional type intersection because the web shared catalog type does not declare that property. Shared API types were not altered.
- Expo calls the page loader on focus; web loads on route mount and after successful entry/import. React Router remounts the page on navigation. The page keeps the initial loading state until its async request settles.
- Browser CSV download uses the shared `downloadCsv` helper, which revokes the object URL on a timer; Expo's web branch revokes it immediately. The exported data, filename, BOM, and headers are unchanged.
- No purchase feature was found that is reachable only on Expo native, so no purchase feature is marked decision needed.
