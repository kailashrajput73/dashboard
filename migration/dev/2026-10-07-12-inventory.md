**Status:** Built; manual checks are waiting in `migration/PENDING.md`.

## Built

Migrated Expo `frontend/app/(admin)/inventory.tsx` to `web/src/pages/InventoryPage.tsx` and replaced the `/inventory` placeholder in `web/src/App.tsx`.

The page loads current stock, low-stock rows, and inventory movements using existing `GET /inventory`, `GET /inventory/low-stock`, and `GET /inventory/transactions` helpers. It includes search, Current stock/Low stock/Stock in-out tabs, date filters on movements, report summaries, valuation, low-stock indicators, and CSV export for each view. CSV headers, field order, BOM, and row quoting match Expo. Existing UI, money-format, error-modal, and browser CSV-download helpers are reused; no package, backend, or Expo files changed.

## Expo differences and reasons

- Expo uses React Native safe-area/list/scroll views and touch controls. Web uses DOM elements and CSS styles; filter chips wrap rather than using Expo's horizontal ScrollView. The same three tabs and filters are available.
- Expo uses `useFocusEffect` to refresh on screen focus as well as mount. Web loads on route mount; navigating away and back mounts it again. There is no mutation form on this screen.
- Expo branches to native Linking for CSV export and browser Blob/object URL on web. Web uses shared `downloadCsv`; filenames, BOM, headers, values, and filtered-view scope are retained.
- Export completion message and failure text match Expo. Search fields, date parsing, date validation messages, stock/movement calculations, and empty-state messages match Expo.
- No Inventory feature was found that is unreachable in Expo web, so none is marked decision needed.
