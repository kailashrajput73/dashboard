# Row 18: Settings

**Planned:** Port Expo Settings for catalog taxonomy menu visibility and its temporary full-catalog wipe tool.

**Built:** Added `/settings` with Product type and Product class visibility switches, plus the temporary passcode-protected catalog wipe action and result/error messages.

**Old -> new:** `frontend/app/(admin)/settings.tsx` -> `web/src/pages/SettingsPage.tsx`; route in `web/src/App.tsx`. Reuses `web/src/features/catalog-taxonomy/settings.ts`, `PasscodeConfirmModal`, and `wipeCatalogAll`.

**How it works:** The switches load and persist the existing `settings:showProductType` and `settings:showProductClass` values. The wipe calls the existing endpoint with admin contact and passcode, then displays the same removal summary as Expo.

**API calls:** `POST /catalog/wipe-all`.

**Differences from Expo:** Uses responsive HTML controls and the shared web UI components; values, labels, persisted keys, confirmation, and endpoint match Expo.

**How to test:** Toggle each setting and navigate away/back; verify the sidebar item reflects the setting and the choice persists on reload. Do not wipe real data. If authorized, use an isolated disposable database to confirm cancel does nothing and confirmation requires contact/passcode and reports removed counts. Run `npm run build` from `web/`.

**Caution:** Wipe permanently deletes the full catalog tree and pricing history. It is marked temporary for removal before production.
