# Row 19: Dashboard snapshot

**Planned:** Port Expo's live operations snapshot and dashboard module shortcuts.

**Built:** Added `/dashboard` with catalog/stock/low-stock/RFQ/partner/dispatch metrics, pending RFQs, top and slow-moving products, API error details, and the Expo module shortcut grid.

**Old -> new:** `frontend/app/(admin)/dashboard.tsx` -> `web/src/pages/DashboardPage.tsx`; route in `web/src/App.tsx`.

**How it works:** Calls the existing snapshot endpoint, loads the saved company name, and reads the existing taxonomy visibility settings before rendering the corresponding module shortcuts. Metric cards and pending RFQs navigate to their existing web routes.

**API calls:** `GET /dashboard/snapshot`.

**Differences from Expo:** Native layout and router navigation are replaced by responsive CSS grid and React Router. The web sidebar handles sign-out; no dashboard sign-out control is shown, matching Expo's web behavior. This is the same limited operations snapshot, not monthly/quarterly/yearly reporting.

**How to test:** Open Dashboard with an authenticated session. Verify metric values/targets, pending RFQ links, moving/slow panels and module destinations. Confirm Type/Class shortcuts follow Settings. Test a failed snapshot request and verify the API error and URL are shown. Run `npm run build` from `web/`.
