# Row 20: Register

**Planned:** Port Expo's admin account registration screen, validation, automatic sign-in, and Dashboard redirect.

**Built:** Replaced the `/register` placeholder with the registration form. It collects company name, GSTIN, contact number, and passcode; validates required fields and minimum lengths; uppercases GSTIN; registers the account; logs in with the same credentials; saves the admin session; and navigates to Dashboard.

**Old -> new:** `frontend/app/(admin)/register.tsx` -> `web/src/pages/RegisterPage.tsx`; route updated in `web/src/App.tsx`.

**How it works:** Calls the existing unauthenticated register and login wrappers in sequence, then persists the returned session through the existing session helper.

**API calls:** `POST /auth/admin/register`, `POST /auth/admin/login`.

**Differences from Expo:** Replaces React Native inputs/card/navigation with the existing web components and React Router. Validation messages, payload fields, automatic login, and destination match Expo.

**How to test:** Use an isolated test account. Verify empty company/GSTIN, contact shorter than six characters, and passcode shorter than four characters are rejected. Register with valid details and confirm the new session opens Dashboard; verify an existing account link opens Login. Run `npm run build` from `web/`.

**Caution:** Registration creates a persistent admin account. Avoid creating disposable users on a production backend.
